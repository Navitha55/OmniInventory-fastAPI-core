# OmniInventory 📦

A modern, full-stack inventory management system built with a responsive **React (Vite)** frontend styled in a clean Emerald/Teal aesthetic.


## 📂 Project Directory Structure

```text
omniInventory-fastAPI-core/
│
└── frontend/
    ├── src/
    │   ├── App.jsx          # React component (Dashboard UI, API fetch calls, state management)
    │   ├── App.css          # Custom emerald/teal styling and responsive grid layout
    │   ├── main.jsx         # React DOM entry point
    │   └── index.css        # Global CSS resets
    ├── package.json         # Node dependencies and scripts
    └── vite.config.js       # Vite bundler configuration
